# Guide 排版设计系统

所有游戏共用 `public/guide.css`。`public/styles.css` 负责站点基础样式和游戏库；游戏数据模块只描述内容，不定义字号。新增游戏应加载这两份样式及 `public/guide-layout.js`，复用现有语义结构。

## 字体与层级

以下为默认 16px 浏览器字号下的尺寸，实际使用 rem，尊重用户字号设置。

| 角色 | 手机 | 640px 及以上 | 字重 / 行高 |
| --- | --- | --- | --- |
| 游戏名 h1 | 32–44px，随视口缩放 | 960px 起 32px | 700 / 手机 1.15，桌面 1.3 |
| 手册标题 h2 | 24px | 28px | 700 / 1.4 |
| 章节标题 h3 | 20px | 20px | 700 / 1.4 |
| 正文、导言、列表、表格、回答 | 16px | 16px | 400 / 中文 1.85，英文 1.7；表格 1.65 |
| 回顾题目 | 16px | 16px | 400 / 正文行高，深蓝色 |
| 展开入口 | 16px | 16px | 600 / 1.6 |
| 答案选项 | 16px | 16px | 400 / 1.65 |
| 导航、图注 | 14px | 14px | 400；导航标签 600 / 1.5–1.65 |

- 中文优先使用苹方，回退到 Noto Sans SC、微软雅黑。英文使用系统无衬线字体。
- 字重只使用 400、600、700 三档。用间距与分组建立层级，不用全段加粗或缩小正文来挤内容。
- 中文不加字间距，使用严格标点换行；英文正常单词换行，过长名称允许应急折行。
- 正文使用深灰蓝，次要信息使用 muted 色；蓝色主要标识交互入口。答题对错同时提供文字、图标和颜色。

## 间距与布局

- 共用 4 / 8 / 12 / 16 / 24 / 32 / 48px 间距变量。
- 水平分隔线只用于章节之间（包括回顾成绩章节）。章节内部的细则、嵌套说明、信息卡内部和弹窗标题使用留白分组；表格使用交替行底色。卡片与交互控件的完整外框继续保留。
- 手机使用白色页面，顶部封面通栏显示，无边框和圆角；图片底部渐变至白色，与正文背景衔接；深色游戏名叠在渐变区域，确保可读性。规则面板去掉外框、圆角及浅蓝外围底色；页边距 16px，文章不再叠加水平内边距。段间 16px，章节分隔线上下各 32px。
- 正文最大宽度 42rem，宽屏通过增加留白与侧栏扩展，不无限拉长文字行。
- 规则页头部只显示封面和游戏名，不显示年份、简介、作者、出版社或机制。正文从导言开始，不再重复显示“××怎么玩”标题。小于 960px 时头图高为 20–28rem，随视口宽度缩放；顶部返回图标和语言选择器使用至少 44px 的浅色胶囊控件，覆盖在图片上。960px 起封面与游戏名横向排列。游戏元数据仍保留在数据源中供聊天等功能使用。
- 小于 960px 使用右下角 56px 对话气泡按钮，打开铺满可视区域的原生模态聊天窗口，无外边距或圆角。使用右上角关闭按钮或 Escape 关闭，关闭后恢复阅读位置和焦点；草稿、对话及进行中的回复保留。
- 聊天窗口适配安全区域与可视视口高度，弹出键盘时保持输入区可见；打开时先聚焦关闭按钮，用户点输入框后才唤起键盘。背景页面在窗口打开时锁定滚动。
- 手机发送有效消息后让输入框失焦以收起键盘，方便阅读回答；桌面发送后继续聚焦输入框。空消息或正在发送时不改变焦点。
- 聊天输入区聚焦时只改变外层边框颜色，不叠加文本框内部的蓝色轮廓；关闭触摸点击高亮，保留文字选择与光标。
- 请求失败显示独立错误状态：深红文字、浅红底色、红色边框，明确标注“请求失败”并提示稍后重新发送。失败消息使用警报语义，不作为正常回答加入对话历史。
- 960px 起规则和对话并排；1280px 起目录进入左侧栏并默认展开。
- 小于 960px 时目录入口位于提问按钮上方，使用白底列表图标；点击打开全屏目录，长列表在窗口内滚动。选中章节后先关闭窗口，再跳转并将焦点移到章节标题。直接关闭则回到原阅读位置。
- 960–1279px 使用文章顶部的可展开目录，1280px 起恢复左侧目录栏。
- 目录随阅读位置高亮当前章节（蓝色背景、左侧标记与加粗），同时设置 `aria-current="location"`。打开手机目录时自动滚到当前项；弹窗打开期间保持高亮，滚动目录不会改变正在阅读的章节。
- 图例保持原比例，可点击查看原图。表格在自己的区域横向滚动，不压缩正文，也不让整个页面横向滚动。
- 按钮、目录和语言选择器至少 44px 高，答案至少 48px 高；文本框沿用 16px 正文。

## 维护规则

1. 新内容先选择语义角色（章节、正文、图注、题目），再使用共享类；不为某个游戏单独定义字号。
2. 调整字级、行高、间距时修改 `--guide-*` 变量。新增例外必须说明内容需求。
3. 中英文均检查 320px、390px、768px 和 1280px；检查长标题、展开表格、答题反馈、聊天切换和键盘焦点。
4. 检查页面无横向溢出，放大文字后不裁切，移动目录收起后跳转位置正确。
5. 运行现有 guide 与 chat 测试；规则内容修改另外进行来源核查。
