# 可收缩内容与互动题

规则详情、图解、附录的嵌套说明和 quiz 共用 `public/disclosure.css` 与 `public/disclosure.js`。组件负责外观、箭头、键盘语义与动效；`public/quiz-feedback.js` 只负责答案状态、自动收起计时和重置。

| 项目 | 统一规则 |
| --- | --- |
| 容器 | 中性浅底色、1px 灰色边框、8px 圆角；与前文间距 16px |
| 标题 | 16px 正常字重，沿用中英文正文行高，长标题换行 |
| 点击范围 | 整行标题，内边距 16px，至少 44px 高 |
| 箭头 | 右侧 20px 下箭头，展开后旋转 180° |
| 内容 | 左右和底部 16px 内边距，图片保持原比例，表格独立滚动 |
| 动效 | 高度 320ms 缓出，内容同步淡入或淡出；快速操作可反转 |
| 无障碍 | 明确的展开状态与内容关联、键盘焦点；隐藏内容不可聚焦；尊重减少动态效果设置 |

默认状态由内容用途决定：规则详情保留作者设定的展开状态，quiz 初始展开。未作答的 quiz 与规则详情使用相同的中性样式；答对使用浅绿色，答错使用浅红色，同时通过答案反馈和无障碍名称说明结果。

所有状态均可手动收起、展开，答案不会清空。答对后停留 1.6 秒再自动收起；手动操作取消待执行的自动收起。指南不展示总分或回顾成绩页。设计系统示例页提供重置按钮，用于反复演示交互。页面目录由导航组件管理，不使用内容卡片样式。

新增规则详情继续使用原生 `details/summary`；在内容渲染后调用 `initializeDisclosures(container)` 即可增强，未执行脚本时仍可原生展开。当前指南通过 `initializeQuizFeedback(container)` 一并初始化两类内容。程序修改 `details.open` 时会同步组件状态。

预览：`/design/disclosures.html`。字号沿用文字排版系统；修改间距、颜色、箭头与动画时，统一修改 `--disclosure-*` 变量。
