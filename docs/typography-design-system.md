# 文字排版设计系统

目标：让玩家快速分辨游戏名、规则主题、规则正文和图注；保持中英文、不同游戏与屏幕尺寸的一致性。

`public/typography.css` 是文字设计变量的唯一来源，由 `styles.css` 导入。`guide.css` 将现有 `--guide-text-*` 变量映射到这些变量；按钮也引用同一字体、正文字号和标签字重。排版展示页为 `/design/typography.html`。

## 文字角色

下表像素值以浏览器默认 16px 根字号为准，实际使用 rem；手机不缩小正文。

| 角色 | 变量 / 默认字号 | 字重 | 行高 | 用途 |
| --- | --- | --- | --- | --- |
| 游戏名 | `--type-display` / 32px | 700 | 1.3 | 桌面页头 |
| 封面游戏名 | `--type-display-cover` / 32–44px | 700 | 1.15 | 手机头图，允许换行 |
| 分组标题 | `--type-title` / 24px，640px 起 28px | 700 | 1.4 | 需要分组的新页面；不重新引入“××怎么玩”标题 |
| 章节标题 | `--type-section` / 20px | 700 | 1.4 | 规则主题、弹窗标题、首页游戏卡标题 |
| 正文 | `--type-body` / 16px | 400 | 中文 1.85 / 英文 1.7 | 导言、规则、问答、题目与解释 |
| 标签 / 展开入口 | 16px | 600 | 1.6；按钮 1.5 | 可操作的短文字 |
| 图注 / 辅助信息 | `--type-caption` / 14px | 400 | 1.65 | 图注、进度、次要说明 |
| 紧凑文字 | 16px | 400 | 1.65 | 表格、答题选项；仍允许换行 |

字体：英文采用系统无衬线字体；中文优先苹方，其次 Noto Sans SC、微软雅黑。品牌字标可以保留品牌字体，其余内容不逐游戏自定义字体。只使用 400、600、700 三档字重。

## 颜色与强调

- 标题使用 `--type-color-heading`，继承站点深蓝灰 `--ink`。
- 正文使用 `--type-color-body`（#344b5c）；图注使用 `--type-color-caption`，继承 `--muted`。
- 蓝色主要标记交互入口，不把整段规则染成强调色。
- 强调只用于影响理解的短词、数字或条件，使用 600 字重；不加粗整段正文。
- 答题对错保留颜色、图标和文字说明；不能只凭颜色表达结果。

## 阅读节奏

- 正文最大宽度 `--type-measure: 42rem`。手机正文侧边距 16px；宽屏扩大外围留白，正文不无限拉长。
- 段落间隔 16px；章节分隔线上下各 32px。标题与规则摘要使用既有 12px 间隔。
- 中文使用自然断行，不人为增加字间距；英文保持单词边界，极长字符串可应急折行。
- 长标题自然换行，不截断、不使用省略号。用户放大字体时，容器应自然增高。
- 不用空段落、重复换行或空格制造布局。内容文件只描述文字与语义，样式由共享文件控制。

## 图例与图注

所有游戏共用 `.rule-example`：**无边框、无底色、无卡片圆角、无外层内边距**。图片与文章背景自然衔接，保持原比例；上下留白 24px，图片与图注之间 12px。图注使用 14px、400 字重、1.65 行高。

图片仍可点击查看原图，保留可访问名称与键盘焦点描边。焦点描边仅在键盘操作时出现，不是常驻装饰边框。分步骤说明属于正文，保持 16px，不因位于图片下方就整体缩成图注。

## 实现约定

新页面可使用 `.type-display`、`.type-title`、`.type-section`、`.type-body`、`.type-label`、`.type-caption`。这些是视觉角色，不替代正确的 HTML 标题、段落、列表、表格和 `figure/figcaption` 语义。

调整全站字号或字体时修改 `typography.css`；不要在游戏模块中硬编码字号。按钮的形状、尺寸和状态继续由[按钮设计系统](button-design-system.md)管理。

验收涵盖中英文、320/390/768/1280px、长标题、图例和图注、表格横向滚动，以及放大文字后的内容完整性。
