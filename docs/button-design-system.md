# 按钮设计系统

所有页面在页面样式之后加载 `public/buttons.css`。按钮外观只在这份文件中维护；页面 CSS 只负责位置、显隐与布局。示例页为 `/design/buttons.html`，与真实页面加载相同样式。

## 基础规范

| 属性 | 规范 |
| --- | --- |
| 文字 | 系统无衬线字体，1rem / 600，行高 1.5；中英文一致 |
| 普通高度 | 最小 2.75rem（默认 44px），长文字可换行增高 |
| 悬浮按钮 | 3.5rem（默认 56px） |
| 圆角 | 999px 胶囊；等宽高图标按钮自然成为圆形 |
| 内边距 | 上下 .5rem，左右 1rem；图标按钮为 0 |
| 图标 | 普通 22px，悬浮入口 24px；继承文字颜色 |
| 间距 | 图标与文字 8px；相邻独立按钮建议 8–12px |
| 阴影 | 仅悬浮入口与图片上导航使用共享柔和投影 |

颜色、尺寸、字重和反馈时长由 `--button-*` 变量定义；不要在游戏专属文件中重新设置。

## 角色与用法

每个按钮添加 `ui-button`，并选择一个外观角色。`ui-button--secondary` 使用基础白底描边样式。

| 角色类 | 外观 | 当前应用 |
| --- | --- | --- |
| `ui-button--primary` | 实心蓝底、白字 | 提问悬浮入口、发送 |
| `ui-button--secondary` | 白底、浅色边框、蓝字 | 目录悬浮入口、重新作答、视图切换 |
| `ui-button--quiet` | 浅蓝灰底、深色图标 | 关闭弹窗 |
| `ui-button--glass` | 半透明白底、深色文字、柔和投影 | 返回、首页和指南的语言选择器 |

尺寸与角色分开组合：`ui-button--icon` 用于只有图标的按钮；`ui-button--floating` 扩大到 56px，并添加投影。`ui-select` 保留普通原生下拉选择和箭头空间。语言切换使用同样的胶囊外观：美国旗代表英语、中国旗代表中文，旗帜来自本地 SVG；展开的原生菜单仍显示语言名称。透明原生 select 覆盖图标区域，保留键盘和手机选择器，焦点描边显示在外层胶囊上。

```html
<button class="ui-button ui-button--secondary" type="button">重新作答</button>
<button class="ui-button ui-button--primary ui-button--icon" aria-label="发送消息" type="submit">
  <!-- 继承 currentColor 的 SVG，设置 aria-hidden="true" -->
</button>
```

## 状态

- 默认：使用角色对应底色与文字颜色。
- 悬停：支持鼠标悬停的设备上改变底色；不改变尺寸，不在触屏上遗留悬停效果。
- 按下：底色加深并下移 1px，140ms 反馈；减少动态效果模式取消位移与过渡。
- 键盘焦点：3px 蓝色外描边，外偏移 3px；不移除浏览器键盘导航能力。
- 选中：用 `aria-pressed="true"` 驱动浅蓝底与蓝色边框，状态不能只靠自定义类表达。
- 禁用：原生 `disabled`，灰底灰字、无投影和按下位移；不以低透明度处理整个按钮。若使用 `aria-disabled`，调用方还必须阻止操作，该属性只表达语义与样式。
- 发送中：现有聊天禁用发送按钮，并在对话区域显示生成状态；不改变按钮宽度。

导航用 `<a>`、操作用 `<button>`、语言用 `<select>`。图标按钮必须有当前语言的可访问名称。操作按钮在表单外显式使用 `type="button"`，发送按钮使用 `type="submit"`。

答题选项仍是多行单选行，目录条目仍是列表导航，规则展开仍使用原生 `details/summary`。这些阅读控件保留适合文字排版的形状，不套用胶囊按钮外观。

## 检查

新增控件需要检查中英文、320/390/768/1280px、44px 触控区域、键盘焦点、禁用与选中状态。颜色调整同时检查白字与蓝底的对比度。业务行为使用既有测试；样式通过真实浏览器检查。
