### 用词决定

| 项目 | 网上用法及本稿决定 |
| --- | --- |
| 游戏名 | 采用“大创造时代”，保留 Age of Innovation 便于搜索。 |
| 基本资源 | 采用工具、钱币、学者、书籍、魔力；不沿用《神秘大地》中的其他资源名称。 |
| 建筑 | 采用工坊、公会、学校、大学、宫殿、高塔、纪念碑、扩建。 |
| 学科 | 采用银行学、法学、工程学、医学；与黄、蓝、褐、白对应。 |
| 玩家组件 | 采用计划板、计划卡、部族板块；“部族”与平台上的“种族”是同一概念。 |
| 板块 | 社区常见“特权片、创造片、能力片、城市片、宫殿片”；本稿统一把“片”写为“板块”，避免同一组件混用多个后缀。 |
| 轮次目标 | 社区称“回合加分片”；本稿用“轮次计分板块”，将全局六轮与玩家单次回合区分。 |
| 相邻关系 | 社区有“直接相邻／间接相邻”的表达。按英文的逻辑集合，本文译为“直接相邻／可达范围”：可达包含直接相邻及航行等方式到达，不能反向推成直接相邻。 |
| Pass | 采用“宣告结束行动”，清楚表示退出本轮行动阶段；保留英文 Pass 便于核对。 |
| 部族专名 | 采用社区使用的神佑者、猫人、哥布林、幻术师、发明家、蜥蜴人、鼹鼠人、僧侣、航海家、先知、哲学家、通灵师，并逐项保留英文。Omar 对应“先知”属于中文社区译名，不是对英文的字面翻译。 |
| 创造专名 | 未核实到全部十八项均有稳定统一译名；中文作为工作译名，逐项保留英文。核心规则组件用词仍统一。 |

这些检索支持本稿与已有中文社区资料保持一致，但不足以证明所有名称都是官方中文出版用词。
